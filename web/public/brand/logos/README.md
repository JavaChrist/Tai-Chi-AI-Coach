# Brand / logos

## Convention

- préfixe : `tai-chi-ai-coach-logo` ;
- SVG privilégié ;
- transparence autorisée ;
- versions light/dark pour fond sombre / clair.

## Fichiers attendus

| Fichier | Format | Transparence | Rôle | État |
| --- | --- | --- | --- | --- |
| `tai-chi-ai-coach-logo.svg` | SVG | oui | Logo principal complet | manquant |
| `tai-chi-ai-coach-logo-compact.svg` | SVG | oui | Version compacte (header) | manquant |
| `tai-chi-ai-coach-logo-light.svg` | SVG | oui | Sur fond sombre | manquant |
| `tai-chi-ai-coach-logo-dark.svg` | SVG | oui | Sur fond clair | manquant |

Tant que les fichiers sont absents, l’UI utilise le fallback textuel `AppBrand`.
