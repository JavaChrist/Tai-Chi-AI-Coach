# Brand / icons

## Convention

- préfixe : `tai-chi-ai-coach-` ;
- minuscules, séparateur `-` ;
- PNG opaque pour PWA (sauf indication contraire) ;
- zone de sécurité maskable : contenu important dans ~80 % du centre.
