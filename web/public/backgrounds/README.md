# Backgrounds

Arrière-plans décoratifs (gradients exportés, textures légères, scènes calmes).

## Convention

- minuscules, séparateur `-` ;
- WebP ou SVG ;
- privilégier des fichiers légers (mobile first).

## Exemples

| Fichier | Format | Usage | État |
| --- | --- | --- | --- |
| `app-shell-soft.webp` | WebP | Atmosphère app | manquant |
| `session-calm.svg` | SVG | Fond séance | manquant |

Aucun arrière-plan n’est obligatoire au MVP-004.
