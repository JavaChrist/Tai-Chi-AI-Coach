# Hero — Light

Exports clairs des Hero Backgrounds (MVP-008B — Sprint 3).

**Source obligatoire :** `../masters/MASTER_HERO_<FAMILY>.webp`  
Aucune variante ne doit être créée indépendamment du Master.

Rice Paper · Morning Mist · Soft Jade · Warm Sand · Morning Sky
