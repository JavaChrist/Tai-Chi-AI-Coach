# Sections

Rôle : variations légères pour séparer une section, soutenir un état vide ou un bilan.

Intensité : **plus discrète** que les Hero.

Ne jamais concurrencer carte, titre, CTA ou illustration métier.

## Familles

| Famille | Émotion | Usage typique |
| --- | --- | --- |
| `section-bamboo` | Souplesse | Respirations bibliothèque / listes |
| `section-mist` | Respiration | Bilan, transitions |
| `section-paper` | Carnet / intimité | Profil, textes longs |
| `section-stone` | Ancrage | Préférences, stabilité |

## Formats et dimensions

- WebP  
- 1600 × 900 (ou ratio équivalent)  
- Recadrage doux supporté  
- Light + Dark

## Nommage

```text
section-<theme>-<variant>-desktop.webp
```

(Viewport section souvent unique ; variantes mobile via CSS `object-position`.)
