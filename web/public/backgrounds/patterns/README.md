# Patterns

Rôle : motifs partiels pour zones secondaires, cartes de respiration, états vides, séparations discrètes.

## Familles utiles uniquement

| Fichier attendu | Rôle |
| --- | --- |
| `pattern-mist.svg` ou `.webp` | Voile / respiration |
| `pattern-bamboo.svg` ou `.webp` | Suggestion verticale discrète |
| `pattern-wave.svg` ou `.webp` | Fluidité très calme (eau évoquée) |

## Limite

Un pattern **ne couvre jamais** tout un écran principal.

Il reste :

- partiel ;
- calme ;
- très faiblement contrasté.

## Formats

- SVG pour motif géométrique / organique simple ;
- WebP / PNG avec transparence sinon.

## Interdits

- wallpaper plein cadre ;
- contraste élevé ;
- motif folklorique saturé ;
- animation.

Tous : **missing**.
