# Textures

Rôle : sensation de matière (papier, bambou, pierre) — jamais une image autonome.

## Familles

| Fichier attendu | Rôle |
| --- | --- |
| `texture-rice-paper.webp` | Fibre Rice Paper, très légère |
| `texture-bamboo-paper.webp` | Suggestion fibre / nervure douce |
| `texture-stone-paper.webp` | Micro-variation minérale mate |

## Contraintes

- très légères ;
- répétables sans rupture visible si tile ;
- compatibles clair / sombre (ou variantes dédiées si nécessaire) ;
- sans bruit numérique excessif.

## Formats

WebP ou PNG. SVG interdit sauf motif géométrique trivial (préférer patterns/).

## Interdits

- bois fortement visible ;
- grain photo lourd ;
- parchemin ancien ;
- papier sale ;
- fissures ;
- métal / plastique / verre.

## Statut

Tous : **missing**.

## Pratique

Une texture quasi imperceptible peut être envisagée uniquement si elle améliore le confort et reste conforme à 12A — jamais un Hero.
