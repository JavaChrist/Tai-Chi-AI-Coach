# Curriculum — médias pédagogiques

Médias associés aux séances et mouvements.

Sous-dossiers :

- `sessions/` — couvertures / visuels de séances ;
- `movements/` — références visuelles de mouvements (`F-004` / `F-007`).

## Convention

- minuscules, séparateur `-` ;
- préfixe `session-` ou `movement-` ;
- **vrai WebP** pour images livrées (ne jamais renommer un PNG en `.webp`) ;
- sources PNG autorisées à côté des livrables WebP ;
- voir aussi `/video` et `/audio`.
