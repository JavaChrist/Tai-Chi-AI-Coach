# Curriculum — médias pédagogiques

Médias associés aux séances et mouvements.

Sous-dossiers :

- `sessions/` — couvertures / visuels de séances ;
- `movements/` — références visuelles de mouvements (ultérieur, `F-004` / `F-007`).

## Convention

- minuscules, séparateur `-` ;
- préfixe `session-` ou `movement-` ;
- WebP pour images ; voir aussi `/video` et `/audio`.

## Exemples

| Fichier | Dossier | Format | Usage | État |
| --- | --- | --- | --- | --- |
| `session-discovery-cover.webp` | `sessions/` | WebP | Couverture séance découverte | manquant |
| `session-initiation-cover.webp` | `sessions/` | WebP | Couverture initiation | manquant |
| `movement-placeholder.webp` | `movements/` | WebP | Placeholder mouvement | manquant |

Ne pas inventer de visuels de mouvements officiels ici.
