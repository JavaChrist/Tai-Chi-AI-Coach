# Placeholders

Fichiers **temporaires** uniquement — jamais présentés comme identité finale.

## Convention

- suffixe ou mention `temp` / `placeholder` dans le nom ;
- documenter clairement le statut `placeholder`.

## Fichiers

| Fichier | Format | Usage | État |
| --- | --- | --- | --- |
| `brand-mark-temp.svg` | SVG | Marque minimale pour tests / secours documentaire | placeholder |

Tout nouveau placeholder doit rester identifiable comme non final.
