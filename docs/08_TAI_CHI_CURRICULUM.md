## 2. Objectif

Définir la progression pédagogique officielle : dans quel ordre apprendre, pourquoi, comment mémoriser, pratiquer, consolider, réviser et devenir autonome.

Ce document explique **comment le Tai Chi est enseigné**.  
Il contient désormais le **corpus minimal MVP** de mouvements fondamentaux (§27), sans figer une forme complète ni un style.

## 3. Philosophie pédagogique

L’application doit fonctionner comme un excellent professeur :

- progression logique ;
- répétition intelligente ;
- autonomie progressive ;
- plaisir d’apprendre.

Alignement avec D-040 : enseigner progressivement, patiemment, simplement — jamais comme une plateforme de consommation rapide de vidéos.

Principes fondateurs du cursus :

1. Les fondations avant les enchaînements.
2. La confiance avant la complexité.
3. La pratique avant la théorie abondante.
4. L’autonomie se gagne ; elle ne s’impose pas.
5. Aucune prétention médicale.
6. Le cursus est **indépendant du style** : on change les contenus, pas la logique d’apprentissage.

## 4. Principes d'apprentissage

1. **Un objectif clair par leçon.**
2. **Voir → comprendre → essayer → répéter → relier.**
3. **Du isolé au composé.**
4. **Du lent et conscient au plus fluide**, sans précipitation.
5. **Droit permanent de répéter** sans pénalité.
6. **Charge cognitive minimale.**
7. **Feedback unique et constructif** à la fois (D-045).
8. **Silence utile pendant la pratique.**
9. **Reprise sans culpabilité** (`F-032`).
10. **Validation experte des contenus** (D-011).
11. **Transférabilité** : la même architecture sert d’autres pratiques douces plus tard.
12. **L’utilisateur reste maître de son rythme.**

## 5. Architecture générale du cursus

```text
Phase Découverte
  ↓
Phase Initiation
  ↓
Phase Progression
  ↓
Phase Consolidation
  ↓
Phase Autonomie
```

| Phase | Intention centrale | Sortie typique |
| --- | --- | --- |
| Découverte | Oser commencer en confiance | Première pratique courte réussie |
| Initiation | Poser les bases gestuelles et rituels de séance | Gestes fondateurs stables |
| Progression | Relier et enrichir | Micro-enchaînements compréhensibles |
| Consolidation | Stabiliser mémoire et calme | Révisions autonomes efficaces |
| Autonomie | Maintenir et affiner sans dépendance excessive | Pratique régulière autodirigée |

Le MVP concentre surtout Découverte + Initiation + début de Progression (`F-003`, `F-013`).

## 6. Phase Découverte

### 6.1 Objectifs

- comprendre le cadre de la pratique dans le produit ;
- réduire la peur de mal faire ;
- découvrir le rituel d’une séance courte ;
- intégrer les consignes de prudence.

### 6.2 Compétences

- savoir où commencer ;
- reconnaître une démonstration simple ;
- pratiquer quelques minutes sans surcharge ;
- s’arrêter en cas de douleur.

### 6.3 Résultats attendus

- première ouverture réussie (`F-033`) ;
- présentation comprise (`F-001`) ;
- prudence lue (`F-016`, `F-031`) ;
- Wow moment / premier succès possible via une séance courte (`F-013`).

## 7. Phase Initiation

### 7.1 Objectifs

- acquérir les gestes fondateurs du style retenu (à choisir plus tard) ;
- installer le cycle démonstration → essai → répétition ;
- créer une habitude de séances guidées courtes.

### 7.2 Compétences

- reproduire un geste isolé avec calme ;
- utiliser vidéo et explication (`F-006`, `F-005`) ;
- reprendre une leçon (`F-032`) ;
- respirer / conclure simplement (`F-014`, `F-015`).

### 7.3 Résultats attendus

- parcours débutant engagé (`F-003`) ;
- bibliothèque utilisée pour révision ciblée (`F-004`) ;
- progression visible sans compétition (`F-010`).

> **NOTE**
>
> « Initiation » correspond au niveau **Débutant** de `docs/07_CONTENT_STRATEGY.md` (D-041).

## 8. Phase Progression

### 8.1 Objectifs

- relier les gestes entre eux ;
- augmenter progressivement la complexité sans perdre la clarté ;
- renforcer la mémoire par enchaînements courts.

### 8.2 Compétences

- enchaîner deux ou plusieurs éléments déjà connus ;
- identifier la prochaine étape sans confusion ;
- demander une clarification (plus tard via `F-019` / `F-020` en V1).

### 8.3 Résultats attendus

- séances un peu plus riches mais toujours terminables ;
- sentiment de progression continue ;
- diminution du besoin d’explication à chaque geste.

## 9. Phase Consolidation

### 9.1 Objectifs

- stabiliser la mémoire gestuelle ;
- fluidifier sans rechercher la perfection garantie ;
- pratiquer avec moins de guidage constant.

### 9.2 Compétences

- réviser de façon autonome via bibliothèque / favoris ;
- reconnaître ses points fragiles sans se juger ;
- maintenir une régularité réaliste.

### 9.3 Résultats attendus

- révisions efficaces ;
- moins d’abandon après pause ;
- préparation éventuelle à des programmes adaptés (`F-035`, V2).

## 10. Phase Autonomie

### 10.1 Objectifs

- rendre l’utilisateur capable de pratiquer sans dépendance excessive au guidage ;
- affiner la qualité perçue de sa pratique ;
- maintenir le plaisir et la régularité sur la durée.

### 10.2 Compétences

- composer ou choisir une séance adaptée à son temps ;
- auto-évaluer sobrement (sans métrique médicale) ;
- revenir aux bases quand nécessaire.

### 10.3 Résultats attendus

- pratique autodirigée régulière ;
- usage éventuel d’enrichissements Premium / personnalisation sans y être forcé ;
- transfert possible vers d’autres pratiques douces à long terme (`F-036`, `F-037`).

> **NOTE**
>
> « Autonomie » correspond au niveau **Maîtrise** de la stratégie de contenu, entendu comme autonomie progressive et non comme perfection.

## 11. Construction d'une leçon

Structure officielle d’une leçon :

```text
Accueil
  ↓
Objectif
  ↓
Démonstration
  ↓
Explication
  ↓
Pratique guidée
  ↓
Pratique libre
  ↓
Retour
  ↓
Révision
  ↓
Fin
```

| Étape | Rôle |
| --- | --- |
| Accueil | Poser le calme ; éventuel guide discret (Mei) |
| Objectif | Une intention unique, compréhensible |
| Démonstration | Montrer (`F-006`, images `F-007`) |
| Explication | Juste assez pour oser essayer (`F-005`) |
| Pratique guidée | Essai accompagné, lent |
| Pratique libre | Silence utile ; appropriation |
| Retour | Feedback court, positif, constructif |
| Révision | Option de revoir le point clé |
| Fin | Clôture calme ; prochaine étape éventuelle |

Règles :

- une notion principale par leçon ;
- pas de marketing dans la leçon ;
- prudence accessible avant pratique réelle.

## 12. Construction d'une séance

Modèle général d’une séance guidée (`F-013`) :

```text
Préparation / prudence
  ↓
Entrée (respiration ou recentrage)
  ↓
Corps de séance (leçons / mouvements du moment)
  ↓
Liaison légère (si phase Progression+)
  ↓
Retour au calme
  ↓
Clôture (reprise / prochaine fois)
```

Principes :

- séance terminable dans un temps réaliste (souvent court pour P-002) ;
- interruption et reprise possibles (`F-032`) ;
- pas d’obligation de tout finir pour « réussir » ;
- le programme quotidien (`F-008`) peut pointer vers une séance adaptée au parcours.

## 13. Gestion de la répétition

- Répéter est une méthode, pas un échec.
- On répète d’abord le même geste, puis le même micro-enchaînement.
- La répétition est proposée, jamais imposée comme punition.
- Après plusieurs réussites ressenties, on élargit.
- Les favoris (`F-011`, V1) soutiennent la répétition ciblée.

## 14. Gestion de la mémorisation

Leviers pédagogiques :

- démonstration visuelle + repère statique ;
- une seule nouveauté à la fois ;
- réactivation espacée par révisions ;
- ancrage dans des séances répétées plutôt que binge de vidéos ;
- verbalisation simple de l’intention du geste (sans jargon inutile).

La mémorisation vise la **reconnaissance corporelle progressive**, pas la récitation théorique.

## 15. Gestion des révisions

- Révision volontaire via bibliothèque (`F-004`).
- Révision suggérée après pause longue ou avant un enchaînement nouveau.
- Révision prioritaire des gestes instables ressentis par l’utilisateur.
- Jamais de « punition de révision » après une absence.
- En V1, l’IA peut proposer une révision (`F-019`) sans l’imposer.

## 16. Gestion de la progression

- Progression visible et calme (`F-010`).
- Ordre imposé pour les fondations ; liberté croissante ensuite.
- On ne saute pas une base pour « aller plus vite ».
- On peut ralentir sans perdre la dignité du parcours.
- Les critères de passage sont qualitatifs (section 20), non compétitifs.

## 17. Gestion des erreurs

1. Reconnaître l’essai.
2. Isoler **une** erreur fréquente non médicale.
3. Redémontrer le détail.
4. Proposer une répétition courte.
5. Si douleur : arrêter et rappeler la prudence ; orienter vers un professionnel compétent si nécessaire.

Jamais : humiliation, comparaison sociale, diagnostic.

En V2, toute correction caméra (`F-021`, `F-022`) reste prudente et faillible.

## 18. Gestion des pauses

- Encourager une pause en cas de confusion, fatigue ressentie, ou séance trop longue pour le moment.
- Proposer de revenir plus tard avec une prochaine étape mémorisable.
- La pause fait partie du cursus.
- La reprise est toujours accueillante (`F-032`).

## 19. Gestion de la motivation

Leviers du cursus :

- clarté de la prochaine étape ;
- petites réussites répétées ;
- plaisir du geste calme ;
- encouragement sobre ;
- sentiment d’autonomie croissante.

Interdits : compétition, culpabilisation, peur, sanctions (D-029, D-045).

## 20. Critères de passage d'un niveau

Aucun seuil chiffré. Principes uniquement :

| Passage | Principe |
| --- | --- |
| Découverte → Initiation | L’utilisateur a osé une première pratique courte et compris le cadre de prudence |
| Initiation → Progression | Les gestes fondateurs abordés sont suffisamment reconnaissables pour être reliés |
| Progression → Consolidation | Les micro-enchaînements sont repris sans confusion majeure permanente |
| Consolidation → Autonomie | L’utilisateur peut réviser et pratiquer avec un guidage réduit tout en gardant le calme |

Règles transverses :

- le ressenti de confiance compte autant que la couverture de contenu ;
- l’absence prolongée ne fait pas reculer « en punition » ; elle peut justifier une révision d’accueil ;
- aucun passage n’exige une posture parfaite.

## 21. Place de Mei

Mei est une **guide**, jamais un professeur envahissant.

Rôle dans le cursus :

- accueillir en début de leçon / séance ;
- éclairer un point court ;
- encourager après un essai ;
- disparaître pendant la pratique libre ;
- ne jamais se présenter comme maître diplômé ;
- rester optionnelle pour le fonctionnement du cursus (`F-023` en V2, non bloquant MVP).

## 22. Place de l'IA

L’IA est un **assistant**, jamais une autorité.

Rôle dans le cursus (surtout V1+) :

- reformuler une explication ;
- proposer une révision ;
- aider à choisir la suite ;
- encourager sans juger.

Elle ne doit pas :

- dicter une vérité technique hors contenu validé ;
- diagnostiquer ;
- culpabiliser ;
- remplacer le parcours structuré.

Détail comportemental : `docs/09_AI_COACH.md`.

## 23. Place du silence

Laisser pratiquer notamment :

- pendant la pratique guidée lente ;
- pendant la pratique libre ;
- pendant la respiration ;
- pendant les enchaînements en cours ;
- en fin de séance calme.

Le silence est une composante officielle du cursus.

## 24. Gestion des contenus Premium

Principes uniquement (détail commercial : `docs/06_BUSINESS_MODEL.md`) :

- le cursus de base (Découverte + Initiation + progression réelle) reste accessible en gratuit ;
- le Premium peut offrir approfondissements, programmes adaptés, personnalisation, continuité avancée ;
- aucun contenu de prudence n’est Premium-only ;
- la qualité pédagogique Premium suit les mêmes règles que le gratuit.

## 25. Validation des contenus

Un contenu de cursus n’est admissible que s’il :

1. est validé par des personnes compétentes ;
2. s’insère dans une phase claire ;
3. porte une intention unique ;
4. reste non médical ;
5. est praticable après consultation ;
6. respecte le ton officiel (D-042) ;
7. permet répétition et reprise ;
8. ne dépend pas d’un style au niveau de l’architecture (seuls les exemples de contenu changent) ;
9. reste cohérent avec les personas cœurs de cible ;
10. n’introduit pas de surcharge inutile.
