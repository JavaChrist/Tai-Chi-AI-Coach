# Mission

Créer la référence officielle de toute l’identité visuelle non interface de Tai-Chi AI Coach.

Ce document ne décrit pas :

- les composants UI ;
- le Design System d’interface ;
- les couleurs d’écran applicatif.

Ces éléments sont définis dans `12A_EXPERIENCE_DESIGN_SYSTEM.md`.

Le présent document décrit exclusivement :

- l’univers graphique ;
- les paysages ;
- les illustrations ;
- les photographies ;
- les logos ;
- Mei ;
- les backgrounds ;
- les textures ;
- les ambiances.

Il doit permettre à un designer, un illustrateur, un photographe ou une IA de produire des visuels parfaitement cohérents avec Tai-Chi AI Coach.

# Chapitre 1 — Philosophie visuelle

---

## 1.1 Objectif

Ce chapitre définit l’âme graphique du produit.

Avant toute image,

une seule question :

> Est-ce que ce visuel invite à ralentir ?

Si la réponse est non,

le visuel est refusé.

---

## 1.2 L’âme graphique

Tai-Chi AI Coach possède une âme de carnet de pratique et de dojo intérieur.

Le graphisme évoque :

- le silence d’un matin ;
- la patience d’un arbre ;
- la douceur d’une brume ;
- la dignité d’un geste lent.

Jamais :

- l’éclat d’un stade ;
- la vitesse d’une application sportive ;
- le luxe ostentatoire ;
- le folklore caricatural.

L’âme graphique est :

calme, naturelle, précise, humble.

---

## 1.3 Émotions recherchées

Tout asset doit transmettre au moins une de ces émotions :

| Émotion | Sensation |
| --- | --- |
| Calme | Le corps se pose |
| Respiration | L’espace s’ouvre |
| Sérénité | Rien n’urge |
| Confiance | On peut commencer |
| Douceur | Aucune pression |
| Présence | On est ici, maintenant |
| Continuité | Un chemin, pas une course |

L’émotion dominante du produit reste :

**le calme.**

---

## 1.4 Émotions interdites

Aucun asset ne doit transmettre :

- urgence ;
- compétition ;
- performance ;
- domination ;
- anxiété ;
- spectacle ;
- séduction commerciale agressive ;
- mysticisme excessif ou ésotérisme commercial ;
- folklore stéréotypé.

Si un visuel « crie »,

il est faux.

---

## 1.5 Le rôle des paysages

Les paysages ne sont pas décoratifs.

Ils sont des respirations.

Ils rappellent que la pratique s’inscrit dans :

- la nature ;
- le temps long ;
- le silence.

Un paysage n’illustre jamais une performance.

Il offre un espace mental.

---

## 1.6 Principe fondamental

L’image doit disparaître derrière la sensation.

Si l’utilisateur se souvient d’un effet,

et non d’un calme,

le visuel a échoué.

# Chapitre 2 — Univers graphique

---

## 2.1 Objectif

Définir l’ambiance générale dans laquelle vivent tous les assets.

---

## 2.2 Ambiance générale

L’univers de Tai-Chi AI Coach est :

- matinal ;
- aéré ;
- légèrement brumeux ;
- naturellement éclairé ;
- silencieux.

Il évoque un espace personnel de pratique,

jamais un studio publicitaire.

---

## 2.3 Japon traditionnel

Le Japon traditionnel inspire :

- la retenue ;
- la composition ;
- le respect du vide ;
- la beauté des matières simples.

Il n’autorise jamais :

- les clichés saturés ;
- les temples en néon ;
- les motifs « souvenir » ;
- les pastiches caricaturaux ;
- une appropriation décorative vide de sens.

L’inspiration est culturelle et atmosphérique.

Jamais folklorique.

---

## 2.4 La nature

La nature est le premier langage visuel du produit.

Elle apparaît comme :

- un horizon ;
- une texture de lumière ;
- une suggestion de végétal ;
- un silence vert.

Elle n’apparaît jamais comme :

- une jungle dense ;
- une nature hostile ;
- une image stock générique de « wellness ».

---

## 2.5 Le silence

Le silence est une matière visuelle.

Il se traduit par :

- de larges zones calmes ;
- peu d’éléments ;
- une hiérarchie claire ;
- l’absence de détails inutiles.

Un asset trop rempli est un asset bruyant.

---

## 2.6 La lumière du matin

La lumière de référence est celle du matin.

Elle est :

- douce ;
- latérale ou diffuse ;
- légèrement dorée ou nacrée ;
- jamais crue.

Elle évoque un début de journée,

pas un coucher dramatique,

pas un midi écrasant.

---

## 2.7 La respiration

Chaque image doit laisser respirer le regard.

Le vide n’est pas un oubli.

Le vide est une intention.

---

## 2.8 Ce que Tai-Chi AI Coach n’est pas

Tai-Chi AI Coach n’est pas :

- une application de sport ;
- une application de fitness ;
- un tableau de bord ;
- une marque lifestyle agressive ;
- une expérience de réalité virtuelle spectaculaire ;
- un jeu ;
- une publicité pour un voyage ;
- une application médicale ;
- un produit « tech » brillant.

Tai-Chi AI Coach est :

un espace calme pour pratiquer.

---

| Bambou flou | Nature, verticalité douce |

---

## 2.10 Motifs d’ambiance interdits

| Motif | Raison |
| --- | --- |

| Fumée dramatique | Théâtralisation |
| Éclairs / orages | Anxiété |

| Particules magiques | Fantasy commerciale |
| Filtres saturés | Publicité |

# Chapitre 3 — Les paysages

---

## 3.1 Objectif

Définir les paysages officiels et leurs règles d’emploi.

Un paysage sert à offrir un horizon intérieur.

Jamais à remplir.

---

## 3.2 Montagnes

### Nature

Montagnes lointaines, silhouettes douces, couches successives.

Souvent partiellement voilées.

### Quand les utiliser

- Hero d’accueil ;
- moments de progression personnelle ;
- respirations entre sections ;
- fonds de splash très discrets.

### Quand ne jamais les utiliser

- derrière un contenu dense ;
- en arrière-plan de pratique guidée ;
- avec des sommets agressifs ou alpins « extrêmes » ;
- comme décor de performance.

Les montagnes évoquent la patience.

Jamais la conquête.

---

## 3.3 Bambous

### Nature

Tiges verticales, verts désaturés, flou de profondeur, lumière filtrée.

### Quand les utiliser

- Hero « nature » ;
- bibliothèque / invitation à choisir ;
- transitions calmes ;
- textures très légères.

### Quand ne jamais les utiliser

- en motif répétitif envahissant ;
- en premier plan saturé ;
- comme « papier peint » dense ;
- avec un vert fluo ou tropical.

Les bambous évoquent la souplesse.

Jamais la décoration chinoiserie.

---

## 3.4 Brume

### Nature

Voile clair, profondeur progressive, horizons adoucis.

### Quand les utiliser

- Splash ;
- Hero mist ;
- états vides poétiques ;
- transitions d’ambiance.

### Quand ne jamais les utiliser

- si elle réduit la lisibilité d’un texte important ;
- si elle devient un filtre gris triste ;
- si elle masque un sujet principal nécessaire.

La brume ouvre.

Elle n’obscurcit pas.

---

## 3.5 Pierres

### Nature

Pierres lisses, galets, dalles, jardins secs évoqués avec retenue.

### Quand les utiliser

- ancrage ;
- profil / préférences (stabilité) ;
- détails de texture ;
- compositions minimalistes.

### Quand ne jamais les utiliser

- en amas chaotique ;
- comme symboles funéraires ;
- avec des reliefs agressifs.

La pierre rassure.

Elle n’alourdit pas.

---

## 3.6 Eau

### Nature

Surface calme, reflets doux, rivage discret, aucun courant violent.

### Quand les utiliser

- respiration ;
- bilan de séance ;
- moments de clôture ;
- ambiances de continuité.

### Quand ne jamais les utiliser

- vagues, cascades spectaculaires ;
- eau trouble inquiétante ;
- effets miroir excessifs.

L’eau accompagne.

Elle ne dramatise pas.

---

## 3.7 Ciel

### Nature

Ciel matinal, clair, parfois laiteux, rarement bleu saturé.

### Quand les utiliser

- ouverture ;
- Hero morning ;
- sensation d’espace.

### Quand ne jamais les utiliser

- couchers flamboyants ;
- ciels orageux ;
- gradients artificiels « wallpaper ».

Le ciel respire.

Il ne peaufine pas un effet.

---

## 3.8 Hiérarchie des paysages

| Priorité | Élément | Rôle |
| --- | --- | --- |
| 1 | Brume / air | Respiration |
| 2 | Lumière | Direction émotionnelle |
| 3 | Horizon (montagne / ciel) | Profondeur |
| 4 | Végétal (bambou) | Présence naturelle |
| 5 | Pierre / eau | Ancrage secondaire |

Jamais inverser cette hiérarchie au profit d’un détail spectaculaire.

---

# Chapitre 4 — Hero Backgrounds

---

## 4.1 Objectif

Définir les règles officielles des fonds Hero.

Un Hero n’est pas une bannière marketing.

C’est un premier souffle.

---

## 4.2 Principes communs

Tout Hero respecte :

| Règle | Exigence |
| --- | --- |
| Composition | Un plan dominant, peu d’éléments |
| Profondeur | Au moins deux plans doux (proche / lointain) |
| Lumière | Matinale ou brumeuse |
| Opacité / présence | Le contenu reste lisible ; le fond ne combat jamais le texte |
| Respiration | Grandes zones calmes, surtout autour du centre utile |
| Personnalité | Calme immédiat, jamais sport |

Les Hero sont full-bleed lorsqu’ils portent une surface d’accueil.

Ils ne deviennent jamais une carte inset décorative.

Aucun badge, sticker ou label flottant sur le Hero.

---

## 4.3 Composition

- horizon bas ou milieu doux ;
- sujet non centré de façon agressive ;
- espace négatif généreux pour marque / titre / CTA ;
- aucun élément parasite au premier plan ;
- aucune personne en performance sportive.

---

## 4.4 Profondeur

La profondeur se construit par :

- flou progressif ;
- brume ;
- couches tonales.

Jamais par un effet 3D spectaculaire.

---

## 4.5 Lumière

Lumière douce, direction stable, contrastes modérés.

Le Hero ne doit jamais sembler « retouché HDR ».

---

## 4.6 Opacité et lisibilité

Lorsqu’un texte se pose sur un Hero :

le fond s’efface suffisamment pour que la lecture reste naturelle.

La lisibilité prime toujours sur le paysage.

---

## 4.8 Fréquence d’usage

Un écran n’utilise qu’**un** Hero dominant.

Jamais plusieurs Hero concurrents.

Les Hero ne se multiplient pas pour « décorer ».

---

## 4.9 Principe fondamental

Le Hero prépare l’esprit.

Il ne vend rien.

# Chapitre 5 — Splash

---

## 5.1 Objectif

Le Splash fait ressentir immédiatement :

**le calme.**

Aucun loader spectaculaire.

Aucune animation décorative.

---

## 5.2 Composition

Le Splash est extrêmement simple.

Il contient :

- le logo ;
- le nom ;
- une respiration (espace) ;
- un fond discret.

Rien d’autre.

Pas de slogan long.

Pas de barre de progression théâtrale.

Pas de particules.

---

## 5.3 Logo

Le logo est centré ou légèrement au-dessus du centre optique.

Il reste le seul sujet.

Taille confortable, jamais monumentale.

---

## 5.4 Background

Fond recommandé :

- `hero-mist` très atténué ;
- ou Surface / Rice Paper pure ;
- ou dégradé extrêmement doux vers Morning Mist.

Le fond ne doit jamais rivaliser avec le logo.

---

## 5.5 Lumière

Lumière matinale uniforme.

Aucun spot.

Aucun halo technologique.

---

## 5.6 Animation

Si une animation existe :

elle est minimale.

Exemples autorisés :

- apparition douce du logo (fondu court) ;
- légère respiration d’opacité (très lente, non permanente).

Interdits :

- bounce ;
- zoom spectaculaire ;
- rotation ;
- confettis ;
- shimmer agressif ;
- boucles infinies voyantes.

Le Splash peut aussi être parfaitement statique.

Le silence est une option valide.

---

## 5.7 Sensation cible

Après deux secondes,

l’utilisateur doit ressentir :

« Je peux ralentir. »

Pas :

« L’application charge. »

---

# Chapitre 6 — Illustrations

---

## 6.1 Objectif

Définir le style officiel des illustrations.

Une illustration renforce une émotion, une compréhension ou une respiration.

Jamais un vide.

---

## 6.2 Style

Style :

- épuré ;
- contemporain ;
- légèrement pictural ou en aplats doux ;
- sans contour agressif ;
- sans cartoon enfantin ;
- sans réalisme photographique parfait (sauf photo réelle).

Les formes sont simples.

Les détails sont rares.

---

## 6.3 Cadrage

- sujet unique ;
- marges généreuses ;
- regard guidé vers le calme, pas vers l’action ;
- peu d’accessoires.

Éviter les cadrages dynamiques type sport.

---

## 6.4 Couleurs

Les illustrations s’alignent sur l’univers :

- verts Soft Jade / Bamboo désaturés ;
- beiges Warm Sand / Rice Paper ;
- gris Zen Stone ;
- accents rares Morning Sky ;
- encre douce Ink, jamais noir pur saturé.

Jamais :

- néons ;
- violet dominant ;
- rouge vif ;
- dégradés « tech ».

---

## 6.5 Lumière

Lumière douce, unique, cohérente avec le matin.

Ombres légères.

Pas de contraste théâtral.

---

## 6.6 Profondeur

Profondeur suggérée par :

- couches ;
- transparence ;
- flou léger.

Jamais par une perspective agressive.

---

## 6.7 Usages autorisés

- états vides (« Commençons ») ;
- onboarding ;
- moments de prudence bienveillante ;
- accompagnement narratif rare ;
- présentation de concepts simples (respiration, posture, chemin).

---

## 6.8 Interdits

Une illustration est refusée si elle contient :

- personnages en performance sportive ;
- musculature mise en avant ;
- armes ;
- symboles de compétition ;
- emojis intégrés ;
- texte long dans l’image ;
- mascottes criardes ;
- style manga saturé ;
- collage chaotique ;
- surplus de détails.

---

## 6.9 Densité

Une bonne illustration se comprend en une seconde.

Si elle demande un déchiffrage,

elle est trop complexe.

---

## 6.10 Principe fondamental

L’illustration disparaît derrière le sentiment.

Si l’on remarque le style avant le calme,

revoir.

---

# Chapitre 7 — Photographies

---

## 7.1 Objectif

Définir la photographie officielle du produit.

Ne jamais produire un rendu publicitaire.

---

## 7.2 Lumière

- naturelle ;
- douce ;
- matinale de préférence ;
- peu de flash ;
- aucun HDR agressif.

Les hautes lumières restent contrôlées.

Les ombres restent transparentes.

---

## 7.3 Profondeur de champ

Profondeur de champ modérée à douce.

Le sujet principal est clair.

L’arrière-plan respire.

Éviter :

- bokeh « luxe » excessif ;
- netteté clinique sur tout le cadre.

---

## 7.4 Couleurs

Couleurs désaturées avec chaleur discrète.

Vert, beige, gris, bleu-gris.

Jamais :

- saturation marketing ;
- filtres Instagram spectaculaires ;
- looks « fitness magazine ».

---

## 7.5 Cadrage

- espace négatif généreux ;
- sujet non écrasé ;
- lignes horizontales calmes ;
- verticales douces (bambou, poteaux, arbres) ;
- éviter les angles dynamiques sportifs.

---

## 7.6 Sujets autorisés

- nature (montagne, brume, eau, pierre, bambou) ;
- intérieurs de pratique épurés ;
- mains / pieds / silhouette en geste lent (avec dignité) ;
- objets simples (bol, tissu, carnet) ;
- lumière dans une pièce calme.

---

## 7.7 Sujets interdits

- squats, haltères, sueur, performance ;
- selfies ;
- foules ;
- hôpitaux / imagerie médicale ;
- promesse corporelle (« avant / après ») ;
- regards camera trop commerciaux ;
- produits de marque visibles ;
- text overlays publicitaires.

---

## 7.8 Personnes

Lorsqu’une personne apparaît :

- attitude détendue ;
- visage apaisé ;
- geste lent ;
- vêtements sobres ;
- jamais une pose de mannequin fitness.

La photographie respecte la dignité.

Elle ne vend pas un corps.

---

## 7.9 Authenticité

La photo doit sembler possible dans la vie réelle.

Pas une publicité.

Pas une série télévisée.

Pas une image générée « trop parfaite » sans imperfection naturelle.

Une légère imperfection de lumière est préférable à un poli artificiel.

---

## 7.10 Principe fondamental

Une photographie réussie laisse un silence.

Pas une envie d’acheter.

---

# Chapitre 8 — Mei

---

## 8.1 Objectif

Décrire l’univers graphique de Mei.

Ce chapitre complète `12A` (Chapitre 8 — Mei, la présence discrète)

sans le contredire.

Mei est une guide virtuelle.

Sa nature virtuelle reste transparente.

Elle n’est jamais présentée comme une personne réelle trompeusement.

---

## 8.2 Univers graphique

Mei vit dans le même univers que le produit :

- lumière douce ;
- fonds épurés ;
- couleurs naturelles ;
- silence autour d’elle.

Elle n’appartient pas à un univers « anime » séparé.

Elle n’appartient pas à un univers « influenceuse ».

---

## 8.3 Apparence générale

Mei évoque :

- la bienveillance ;
- l’équilibre ;
- la retenue ;
- la présence calme.

Traits :

- expression douce ;
- regard accueillant ;
- sourire discret ;
- jamais de mimiques exagérées.

Âge perçu :

adulte, indéterminé avec dignité,

ni enfantin, ni hypersexualisé, ni autoritaire.

---

## 8.4 Vêtements

Vêtements sobres, amples, confortables,

évoquant une pratique douce :

- tons Soft Jade, Bamboo, Warm Sand, ivoire, gris pierre ;
- coupes simples ;
- tissus mats ;
- aucun logo commercial ;
- aucun équipement sportif flashy.

Inspirations possibles :

tenue de pratique contemporaine, kimono / veste légère très stylisée,

toujours avec retenue culturelle.

Jamais :

- costume de scène ;
- armure ;
- tenue de combat agressive ;
- vêtements moulants type fitness.

---

## 8.5 Couleurs de Mei

Palette autour de Mei :

| Zone | Direction |
| --- | --- |
| Peau / lumière | Naturelle, douce |
| Vêtements | Soft Jade, Bamboo, sable, ivoire |
| Accents | Morning Sky rare |
| Fonds | Rice Paper, brume, dojo clair |

Mei ne porte jamais de couleurs néon.

---

## 8.6 Arrière-plans

Fonds :

- unis très doux ;
- brume légère ;
- intérieur de dojo épuré ;
- extérieur flou (bambou / jardin).

Le fond ne raconte pas une autre histoire que Mei.

Transparence autorisée pour avatars et portraits isolés.

---

## 8.7 Langage corporel

Postures :

- ouvertes ;
- équilibrées ;
- sereines ;
- mains détendues ;
- colonne alignée sans rigidité militaire.

Interdits (alignés 12A) :

- bras croisés ;
- doigt pointé vers l’utilisateur ;
- posture dominante ;
- attitude martiale agressive ;
- pose de mannequin publicitaire.

---

## 8.8 Formats d’assets Mei

| Asset | Rôle | Cadre |
| --- | --- | --- |
| Avatar neutre | Présence discrète | Buste / visage, fond transparent |
| Portrait guide | Accompagnement | Buste, regard bienveillant |
| Plein pied | Présentation / posture | Corps entier, marge généreuse |
| Miniature | Listes / rappels | Simplifié, lisible petit |
| Présentation | Introduction narrative | Composition large, Mei non dominante |
| Placeholder | Absence temporaire | Silhouette ou marque douce, jamais anxiogène |

Mei occupe en règle générale au plus 20–25 % de la surface utile lorsqu’elle apparaît dans une composition d’écran (voir 12A).

---

## 8.9 Animations de Mei (direction artistique)

Mouvements :

- lents ;
- fluides ;
- naturels ;
- rares.

Jamais :

- boucles nerveuses ;
- clignements excessifs ;
- gestes répétitifs ;
- lip-sync théâtral.

---

## 8.10 Présence et absence

L’absence de Mei est normale.

Les assets doivent permettre de ne pas l’afficher sans créer un vide gênant.

Aucun asset Mei n’est requis pour le MVP.

La direction artistique prépare V2 et au-delà.

---

## 8.11 Interdits spécifiques

Mei ne doit jamais :

- ressembler à une publicité ;
- promettre des résultats corporels ;
- adopter un ton médical ;
- se présenter comme maître absolu ;
- monopoliser l’image ;
- devenir une mascotte comique.

---

## 8.12 Principe fondamental

Lorsque Mei est réussie,

l’utilisateur a l’impression d’avoir été accompagné.

Sans avoir été dérangé.

Sans avoir douté de sa nature virtuelle.

# Chapitre 9 — Logos

---

## 9.1 Objectif

Définir le système de logos et leurs usages.

Le logo est un repère de confiance.

Jamais un spectacle.

---

## 9.2 Famille de logos

| Variante | Rôle |
| --- | --- |
| Logo principal | Signature complète (symbole + wordmark) |
| Compact | Espaces réduits (header, navigation) |
| Wordmark | Nom seul, lorsque le symbole est déjà présent ailleurs |
| Symbole | Marque minimale, reconnaissance rapide |
| Favicon | Identification navigateur / onglet |

Variantes tonales :

| Variante | Usage |
| --- | --- |
| Logo sombre (sur fond clair) | Usage principal |
| Logo clair (sur fond sombre) | Mode nuit / fonds foncés |

---

## 9.3 Logo principal

Composition :

symbole + nom « Tai-Chi AI Coach ».

Caractéristiques :

- lisible ;
- calme ;
- équilibré ;
- sans ornements excessifs ;
- sans perspective 3D ;
- sans dégradés agressifs.

Le symbole évoque idéalement :

équilibre, souffle, cercle / mouvement lent, végétal discret,

sans devenir un yin-yang cliché saturé,

sans devenir un pictogramme sport.

---

## 9.4 Compact

Version réduite pour header et navigation.

Le symbole reste reconnaissable.

Le wordmark peut être raccourci visuellement si nécessaire,

sans perdre le nom essentiel.

---

## 9.5 Wordmark

Typographie alignée sur l’identité produit :

digne, claire, non sportive.

Jamais de script décoratif illisible.

Jamais de lettres néon.

---

## 9.6 Symbole

Le symbole doit rester lisible :

- en petit ;
- en monochrome ;
- sur fond clair et sombre ;
- en maskable (zone de sécurité).

Il ne dépend jamais d’un détail fin qui disparaît à 16 px.

---

## 9.7 Favicon

Simplification maximale du symbole.

Lisibilité avant fidélité décorative.

Fond cohérent avec Soft Jade / Rice Paper selon support,

sans bordure criarde.

---

## 9.8 Zones de protection

Autour de chaque logo :

une marge de respiration au moins égale à une portion du symbole

(équivalent « un module » de silence).

Aucun élément ne touche le logo.

Aucun effet d’ombre lourde sous le logo.

---

## 9.9 Usages autorisés

- Splash ;
- Header ;
- Écrans d’accueil ;
- Manifeste / installation ;
- Documents officiels ;
- Stores (avec déclinaisons adaptées).

---

## 9.10 Usages interdits

- étirement ;
- rotation décorative ;
- contours néon ;
- logo dans un badge flottant sur photo ;
- multiplication du logo sur un même écran ;
- association à des messages médicaux ;
- association à de la compétition.

---

## 9.11 Fallback

Lorsque le logo vectoriel est absent,

un fallback textuel sobre est acceptable temporairement.

Il ne devient jamais l’identité définitive.

---

## 9.12 Principe fondamental

Le logo se remarque par sa présence calme.

Jamais par son volume.

# Chapitre 11 — Textures

---

## 11.1 Objectif

Définir les textures autorisées.

Les textures sont uniquement suggérées.

Aucune texture ne doit distraire.

---

## 11.2 Rice Paper

### Nature

Fibre légère, grain à peine perceptible, chaleur douce.

### Autorisé

- fonds print ;
- documents ;
- splash très subtil ;
- overlays à opacité extrêmement faible.

### Interdit

- grain bruyant ;
- répétition visible agressive ;
- texture qui réduit la lisibilité.

---

## 11.3 Papier japonais

### Nature

Washi évoqué, fibres longues, transparence douce.

### Autorisé

- supports éditoriaux ;
- moments cérémoniels rares ;
- transitions narratives.

### Interdit

- motif folklorique saturé ;
- collage « scrapbooking ».

---

## 11.4 Bambou

### Nature

Fibre / nervure suggérée, jamais un motif wallpaper dense.

### Autorisé

- détails de bord ;
- Hero bamboo en flou ;
- éléments graphiques secondaires.

### Interdit

- panneau entier saturé de tiges nettes ;
- vert tropical.

---

## 11.5 Pierre

### Nature

Surface minérale mate, micro-variation tonale.

### Autorisé

- ancrage ;
- fonds secondaires très discrets ;
- print.

### Interdit

- relief 3D exagéré ;
- béton brutaliste ;
- pierre funéraire sombre.

---

## 11.6 Règle d’opacité

Une texture d’ambiance reste secondaire.

Si on la remarque avant le contenu,

elle est trop forte.

---

## 11.7 Textures et interface

Conformément à `12A` :

dans l’interface applicative,

papier, pierre et bambou sont d’abord évoqués par la couleur.

Les textures image restent exceptionnelles.

---

## 11.8 Principe fondamental

La texture est un souffle.

Jamais un motif.

- un sujet ;

## 14.8 Application — Splash

- centrage calme ;
- logo seul ;
- fond secondaire ;
- aucun élément concurrent.

## 14.9 Application — Mei

- Mei n’occupe pas tout le cadre utile ;

# Chapitre 15 — Règles d’or

---

## 15.1 Objectif

Fixer les règles absolues de l’univers artistique.

---

## 15.2 Règles d’or

1. **Le calme d’abord.**  
   Tout asset qui accélère est refusé.

2. **La respiration est un contenu.**  
   Le vide est intentionnel.

3. **Une image, une émotion.**  
   Pas de surcharge narrative.

4. **Nature avant spectacle.**  
   Brume, bambou, pierre, eau, montagne — avec retenue.

5. **Jamais le sport.**  
   Aucun code fitness, compétition, performance.

6. **Jamais la publicité.**  
   Pas de pose magazine, pas de promesse corporelle.

7. **Mei accompagne, elle ne domine pas.**  
   Présence discrète, nature virtuelle claire.

8. **Le logo est un repère, pas un show.**  
   Sobriété, marges, lisibilité.

9. **La lumière du matin est la référence.**  
   Douce, claire, non théâtrale.

10. **La texture suggère, elle n’envahit pas.**  
    Rice Paper, papier, bambou, pierre — en retenue.

11. **Cohérence avec 12A.**  
    Aucun asset ne contredit l’Experience Design System.

12. **L’utilisateur et la pratique restent au centre.**  
    L’image sert la pratique, jamais l’inverse.

---

## 15.3 Phrase de validation

Avant d’accepter un asset, poser :

> Est-ce que ce visuel rend Tai-Chi AI Coach plus calme ?

Si la réponse n’est pas clairement oui,

reprendre.

---

## 15.4 Ce que le produit doit évoquer

Immédiatement :

- le calme ;
- la respiration ;
- la sérénité ;
- la pratique du Tai Chi.

Jamais :

- une application web générique ;
- une application de sport ;
- un tableau de bord ;
- un logiciel métier.

---

## 15.5 Conclusion

`12B_VISUAL_ASSET_GUIDE` est la référence officielle de l’univers artistique de Tai-Chi AI Coach.

Il guide designers, illustrateurs, photographes et IA générative.

Il ne remplace pas `12A`.

Il le complète.

Ensemble, ils forment l’identité complète du produit :

- `12A` : l’expérience d’interface ;
- `12B` : l’âme des images.

Lorsque les deux sont respectés,

Tai-Chi AI Coach cesse d’être une collection d’écrans.

Il devient un espace.

Un espace où l’on peut pratiquer.

Lentement.

Avec confiance.

Dans le calme.
