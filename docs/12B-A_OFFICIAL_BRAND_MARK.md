# 1. Objectif

Ce document définit le symbole officiel de Tai-Chi AI Coach.

Il ferme le manque identifié lors de l’audit croisé 12A × 12B :

la forme exacte du Brand Mark.

Sans ce document, chaque production invente un symbole différent.

Avec ce document, une seule forme existe.

---

# 2. Philosophie

---

## 2.1 Nature du Brand Mark

Le Brand Mark ne représente pas uniquement une entreprise.

Il représente :

- le calme ;
- l’équilibre ;
- la respiration ;
- l’accompagnement.

Il doit être immédiatement reconnaissable.

Même sans texte.

---

## 2.2 Ce qu’il n’est pas

Le Brand Mark n’est jamais :

- un pictogramme sport ;
- un badge de compétition ;
- un logo tech néon ;
- une mascotte comique ;
- un yin-yang souvenir saturé ;
- une photographie.

---

## 2.3 Sensation cible

En une seconde :

« équilibre et accompagnement. »

Pas :

« performance. »

Pas :

« folklore. »

---

## 2.4 Lien avec Mei

Mei apparaît dans le Brand Mark comme présence d’accompagnement.

Elle ne représente pas l’application à elle seule.

Conformément à `12A` :

le centre reste l’utilisateur et la pratique.

Le Yin-Yang porte l’équilibre.

Mei porte la relation.

Le nom porte l’identité verbale.

---

# 3. Composition

---

## 3.1 Les trois éléments

Le symbole officiel est constitué de **trois éléments** et d’eux seuls.

| Ordre | Élément | Rôle |
| --- | --- | --- |
| 1 | Yin-Yang | Équilibre — centre de la marque |
| 2 | Mei | Accompagnement — présence secondaire |
| 3 | Nom | Identité verbale — « Tai-Chi AI Coach » |

Aucun quatrième élément n’est autorisé.

Pas d’icône supplémentaire.

Pas de tagline dans le Brand Mark.

Pas de fond paysage intégré au symbole.

---

## 3.2 Élément 1 — Le Yin-Yang

### Rôle

Il représente l’équilibre.

Il constitue le **centre** de la marque.

### Traitement officiel

Le Yin-Yang de Tai-Chi AI Coach est :

- circulaire ;
- géométriquement pur ;
- simplifié ;
- désaturé ;
- calme.

Il n’est **pas** :

- un yin-yang touristique rouge/noir saturé ;
- un yin-yang 3D ;
- un yin-yang animé en permanence ;
- un yin-yang orné de dragons, fleurs ou calligraphies parasites.

### Construction géométrique

Soit `D` le diamètre extérieur du cercle Yin-Yang.

| Règle | Valeur |
| --- | --- |
| Forme | Cercle parfait |
| Diamètre | `D` = module de base du Brand Mark |
| Trait extérieur | Contour fin, épaisseur ≈ `D / 48` (jamais gras) |
| Deux poissons | Demi-cercles classiques, proportions égales |
| Points (yeux) | Diamètre ≈ `D / 12` ; centrés dans chaque moitié |
| Style | Aplat ou très léger modelé ; jamais gloss |

### Couleurs du Yin-Yang (version polychrome officielle)

| Zone | Couleur | Code |
| --- | --- | --- |
| Moitié claire | Rice Paper / Surface | `#F7F6F1` ou `#FFFEF9` |
| Moitié sombre | Soft Jade | `#7A998D` |
| Point sur clair | Soft Jade | `#7A998D` |
| Point sur sombre | Rice Paper | `#F7F6F1` |
| Contour (si nécessaire) | Bamboo | `#456A5D` |

Version monochrome autorisée :

- Soft Jade sur fond clair ;
- ou Rice Paper / blanc cassé sur fond sombre ;
- ou Ink `#243029` en usage print strict.

Jamais de noir pur agressif ni de blanc clinique aveuglant comme seule identité.

### Lecture

Le Yin-Yang doit rester lisible à la taille favicon.

Les détails trop fins sont interdits.

---

## 3.3 Élément 2 — Mei

### Rôle

Elle représente l’accompagnement.

Elle n’est jamais dominante.

Elle dialogue avec le Yin-Yang.

Jamais avec le texte.

### Traitement officiel

Mei dans le Brand Mark est :

- une silhouette ou un buste très simplifié ;
- posture ouverte, calme ;
- visage discret (traits minimaux) ;
- vêtements sobres Soft Jade / Bamboo / ivoire ;
- regard bienveillant, non autoritaire.

Elle n’est **pas** :

- un portrait photoréaliste ;
- une figure pleine page ;
- une mascotte cartoon ;
- une posture martiale ;
- un doigt pointé ;
- un élément plus grand que le Yin-Yang.

### Position relative (construction)

| Règle | Valeur |
| --- | --- |
| Rapport de hauteur | Hauteur de Mei ≤ `0,55 × D` |
| Rapport d’occupation | Surface visuelle de Mei ≤ surface du Yin-Yang |
| Placement (logo principal horizontal) | Mei à droite du Yin-Yang, ou légèrement en bas à droite, en dialogue |
| Placement (symbole seul / icône) | Mei absente **ou** réduite à une suggestion minimale qui ne compromet pas la lisibilité à 16–32 px |
| Distance Yin-Yang ↔ Mei | Entre `0,12 × D` et `0,25 × D` |
| Contact | Mei ne chevauche jamais le centre du Yin-Yang |
| Dialogue | Orientation du regard / du corps vers le Yin-Yang, jamais vers le wordmark |

### Règle Splash / Favicon / PWA

| Support | Mei |
| --- | --- |
| Logo principal / Splash large | Mei présente, secondaire |
| Logo compact | Mei optionnelle ; si présente, très simplifiée |
| Symbole seul ≥ 64 px | Mei optionnelle, ultra-simplifiée |
| Favicon / notification ≤ 32 px | **Mei absente** — Yin-Yang seul |
| Maskable PWA | Yin-Yang centré ; Mei absente |

Cette règle protège la lisibilité.

Elle ne diminue pas le rôle de Mei dans l’univers produit (`12B` ch.8).

---

## 3.4 Élément 3 — Le nom

### Rôle

Le nom accompagne le symbole.

Il ne le remplace jamais.

### Libellé officiel

```text
Tai-Chi AI Coach
```

Orthographe figée.

Tiret dans « Tai-Chi ».

Espaces simples.

Aucune autre graphie officielle.

### Traitement typographique

| Règle | Valeur |
| --- | --- |
| Famille | Fraunces (titres) — cohérente avec `12A` |
| Graisse | Medium / SemiBold (500–600) |
| Casse | Title case tel que ci-dessus |
| Tracking | Légèrement ouvert ; jamais condensé sport |
| Couleur (fond clair) | Ink `#243029` ou Bamboo `#456A5D` |
| Couleur (fond sombre) | Mist Ink / clair doux (voir palette nuit `12A`) |

Interdits :

- script décoratif ;
- italics agressives ;
- outline néon ;
- dégradé dans les lettres ;
- empilement fantaisiste du nom.

### Position du nom

Le nom se place **sous** ou **à droite** du couple Yin-Yang + Mei selon la variante.

Il ne s’intercale jamais entre Yin-Yang et Mei.

Mei ne dialogue jamais avec le texte.

---

# 4. Hiérarchie

---

## 4.1 Ordre absolu

Toujours :

```text
Yin-Yang
    ↓
Mei
    ↓
Nom
```

Jamais l’inverse.

---

## 4.2 Conséquences

| Situation | Règle |
| --- | --- |
| Manque de place | Retirer le nom avant de retirer le Yin-Yang |
| Encore moins de place | Retirer Mei avant de retirer le Yin-Yang |
| Extreme (favicon) | Yin-Yang seul |
| Wordmark seul | Autorisé uniquement si le symbole est déjà visible ailleurs sur la même surface |

Le Yin-Yang n’est jamais omis lorsqu’un symbole de marque est requis.

---

## 4.3 Poids visuel

| Élément | Poids relatif cible |
| --- | --- |
| Yin-Yang | 100 % (référence) |
| Mei | ≤ 55 % de la hauteur du Yin-Yang |
| Nom | Hauteur de capitales ≈ `0,22 × D` à `0,28 × D` (logo principal) |

---

# 5. Zone de protection

---

## 5.1 Règle

Autour du Brand Mark,

laisser une zone vide.

Cette zone est obligatoire.

Aucun texte.

Aucune image.

Aucun composant.

ne peut pénétrer cette zone.

---

## 5.2 Mesure

Soit `D` le diamètre du Yin-Yang dans la déclinaison considérée.

| Zone | Largeur minimale |
| --- | --- |
| Protection autour du Brand Mark complet | `0,25 × D` de chaque côté (haut, bas, gauche, droite) |
| Protection autour du symbole seul | `0,25 × D` |

La zone se mesure depuis le bounding box du Brand Mark (tous éléments inclus).

---

## 5.3 Interdits dans la zone

- boutons ;
- badges ;
- photographies ;
- filets ;
- ombres parasites d’autres objets ;
- textes légaux collés.

Les mentions légales se placent **hors** zone de protection.

---

# 6. Dimensions minimales

---

## 6.1 Principe

Le symbole doit rester parfaitement lisible.

Les tailles ci-dessous sont des **minimums documentaires**.

Les masters SVG officiels pourront préciser des seuils techniques égaux ou plus stricts,

jamais plus permissifs.

---

## 6.2 Logo horizontal (principal)

Composition : Yin-Yang + Mei + Nom sur une ligne visuelle stable

(Mei à droite du cercle ; nom à droite de l’ensemble ou sous l’ensemble selon largeur).

| Support | Largeur minimale recommandée |
| --- | --- |
| Écran | 160 px de large (ensemble) |
| Print | 35 mm de large |

Diamètre Yin-Yang minimal dans cette variante : **24 px** / **6 mm**.

---

## 6.3 Logo compact

Composition : Yin-Yang + Nom court aligné

(Mei absente ou extrêmement simplifiée).

| Support | Hauteur minimale |
| --- | --- |
| Header / navigation | 28 px (hauteur du Yin-Yang ≥ 24 px) |
| Print | 7 mm (hauteur du cercle) |

---

## 6.4 Symbole seul

Composition : Yin-Yang

(Mei absente sous 64 px).

| Support | Taille minimale |
| --- | --- |
| Écran | 24 × 24 px |
| Print | 6 × 6 mm |

---

## 6.5 Icône (PWA / App / Notification)

| Asset | Taille de livraison | Zone utile |
| --- | --- | --- |
| Favicon | 32 × 32 (et SVG) | Yin-Yang centré, marge ≥ 12,5 % |
| PWA 192 / 512 | selon plateforme | Yin-Yang centré sur fond Rice Paper ou Soft Jade |
| Maskable | 192 / 512 | Sujet dans le safe zone central (≈ 80 % centraux) |
| Apple Touch Icon | 180 × 180 | Fond opaque ; Yin-Yang centré |
| Notification | 24–96 px | Yin-Yang seul |

---

## 6.6 Fixation finale

Les tailles minimales exactes des fichiers livrables sont confirmées

lors de la création des SVG officiels,

sans jamais descendre sous les seuils de ce chapitre.

---

# 7. Variantes

---

## 7.1 Catalogue fermé

Le Brand Mark possède **uniquement** :

| Variante | Contenu |
| --- | --- |
| Logo principal | Yin-Yang + Mei + Nom |
| Logo compact | Yin-Yang + Nom (+ Mei optionnelle ultra-simplifiée) |
| Logo clair | Déclinaison pour fonds sombres |
| Logo sombre | Déclinaison pour fonds clairs |
| Wordmark | Nom seul |
| Symbole | Yin-Yang seul (Mei absente en petit) |

Aucune autre variante officielle.

---

## 7.2 Logo principal

Usage de signature.

Yin-Yang + Mei + Nom.

Hiérarchie respectée.

---

## 7.3 Logo compact

Espaces réduits (navigation, header dense).

Priorité : Yin-Yang + Nom.

---

## 7.4 Logo clair / Logo sombre

| Variante | Fond | Yin-Yang | Nom |
| --- | --- | --- | --- |
| Logo sombre | Clair (Rice Paper) | Soft Jade / Rice Paper | Ink ou Bamboo |
| Logo clair | Sombre (Night Paper) | Soft Jade clair / Mist | Texte clair doux |

Ne pas inventer de « logo coloré événementiel ».

---

## 7.5 Wordmark

Nom seul.

Autorisé lorsque le symbole est déjà présent ailleurs sur la même surface

(ex. symbole dans le header, wordmark dans un pied de page — avec parcimonie).

Le wordmark ne devient jamais le seul signe de marque d’un Splash.

---

## 7.6 Symbole

Yin-Yang seul.

Cœur de la reconnaissance sans texte.

---

## 7.7 Variantes interdites

- logo saisonnier ;
- logo « sport edition » ;
- logo animé permanent ;
- logo avec slogan intégré ;
- logo avec photo ;
- logo monocle / stickers ;
- réarrangement Mei au-dessus du Yin-Yang.

---

# 8. Utilisations

---

## 8.1 Logo principal

Utilisé pour :

- Header (desktop large) ;
- Site / application (signature) ;
- Splash ;
- Documentation ;
- Présentations ;
- Supports print majeurs.

---

## 8.2 Compact

Utilisé pour :

- Navigation ;
- Header mobile ;
- Espaces étroits.

---

## 8.3 Symbole

Utilisé pour :

- PWA ;
- Notifications ;
- Favicons ;
- Réseaux sociaux (avatar) ;
- Appareils (homescreen) ;
- Points de reprise d’identité lorsque le texte est redondant.

---

## 8.4 Wordmark

Utilisé pour :

- Coexistence avec un symbole déjà affiché ;
- Contextes éditoriaux sobres.

---

## 8.5 Splash

Composition Splash :

- fond selon `12B` (hero-mist ou Rice Paper) ;
- Brand Mark (logo principal ou symbole + nom) centré ;
- aucune autre signature.

Le Splash n’introduit pas un second logo.

---

## 8.6 Hero

Sur un Hero (`12B` ch.4) :

le Brand Mark peut apparaître en signature discrète

dans une zone calme,

hors collision avec le texte d’écran,

avec zone de protection respectée.

Jamais de sticker flottant sur le paysage.

---

## 8.7 Fonds autorisés sous le logo

| Fond | Autorisé |
| --- | --- |
| Rice Paper / Surface | Oui |
| Night Paper / Surface Night | Oui (logo clair) |
| Photographie très floue / brume | Oui si contraste suffisant |
| Motif dense | Non |
| Dégradé néon | Non |
| Vidéo agitée | Non |

---

# 9. Interdictions

---

## 9.1 Interdits absolus

Ne jamais :

- déformer ;
- étirer ;
- écraser ;
- incliner ;
- recolorer hors palette officielle ;
- changer Mei ;
- changer le Yin-Yang ;
- inverser la hiérarchie Yin-Yang / Mei / Nom ;
- modifier les proportions ;
- ajouter des effets (ombre lourde, glow, bevel, chrome, particules) ;
- ajouter un contour décoratif extérieur ;
- placer le logo dans un autre logo ;
- remplir le Yin-Yang d’une photographie ;
- animer le Yin-Yang en rotation permanente ;
- associer le Brand Mark à une promesse médicale ;
- associer le Brand Mark à une compétition ou un score.

Le Brand Mark est intangible.

---

## 9.2 Recolorations interdites (exemples)

- violet ;
- rouge vif ;
- vert fluo ;
- or clinquant ;
- dégradé Instagram.

---

## 9.3 Modifications de Mei interdites

- nouvelle coiffure « tendance » ;
- tenue fitness ;
- expression exagérée ;
- duplication de Mei ;
- remplacement de Mei par un autre personnage dans le Brand Mark.

Les autres représentations de Mei hors Brand Mark restent régies par `12B` ch.8.

Elles ne modifient pas Mei **dans** le Brand Mark.

---

# 10. Principe fondamental

---

## 10.1 Une seule source

Toute l’identité de Tai-Chi AI Coach repose sur un seul symbole.

Le Brand Mark constitue cette référence.

Toutes les déclinaisons graphiques doivent être construites à partir de lui.

Aucune exception.

---

## 10.2 Phrase de validation

Avant d’accepter un fichier logo / icône / splash de marque :

> Le Yin-Yang est-il le centre ? Mei est-elle secondaire ? Le nom accompagne-t-il sans remplacer ? La zone de protection est-elle libre ? Aucun effet n’a-t-il été ajouté ?

Si une réponse est non,

le fichier est refusé.
