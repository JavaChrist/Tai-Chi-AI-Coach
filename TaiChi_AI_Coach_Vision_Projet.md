# TaiChi AI Coach --- Vision & Plan de Projet

> Version : 0.1 Date : 2026-08-04

## Vision

Créer le coach de Tai Chi le plus accessible et le plus intelligent du
marché.

L'objectif n'est pas simplement de diffuser des vidéos, mais d'offrir un
véritable professeur personnel, capable de guider, motiver et, à terme,
corriger les mouvements grâce à l'intelligence artificielle.

------------------------------------------------------------------------

# Positionnement

TaiChi AI Coach est une PWA construite sur la même base technologique
que les autres applications de l'écosystème.

Stack cible :

-   Next.js
-   TypeScript
-   Tailwind CSS
-   Supabase
-   PWA
-   IA conversationnelle
-   Virtual Humans Studio (avatars)

L'application doit pouvoir partager des composants et des services avec
les autres projets.

------------------------------------------------------------------------

# Roadmap

## Phase 1 --- MVP

Objectif : proposer une première version rapidement.

Fonctionnalités :

-   présentation du Tai Chi
-   histoire
-   bienfaits
-   styles
-   24 mouvements Yang
-   vidéos
-   photos
-   explications détaillées
-   respiration
-   méditation
-   favoris
-   progression
-   historique
-   mode sombre
-   téléchargement de leçons
-   fonctionnement PWA

------------------------------------------------------------------------

## Phase 2 --- Coach personnel

Le professeur devient interactif.

Choix du niveau :

-   débutant
-   intermédiaire
-   avancé

Séances générées automatiquement selon le niveau.

Exemple :

-   respiration
-   échauffement
-   mouvement 4
-   mouvement 5
-   enchaînement
-   relaxation

------------------------------------------------------------------------

## Phase 3 --- IA

La caméra analyse les mouvements.

Détection :

-   tête
-   épaules
-   bras
-   poignets
-   bassin
-   genoux
-   chevilles

Corrections vocales :

-   baisse les épaules
-   transfère ton poids
-   tourne davantage les hanches

------------------------------------------------------------------------

## Phase 4 --- Virtual Humans Studio

Utilisation d'avatars comme professeurs.

Exemples :

-   Tom
-   maître de Tai Chi
-   professeure
-   différents styles

Voix naturelles et démonstrations animées.

------------------------------------------------------------------------

## Phase 5 --- Premium

Programmes spécialisés :

-   30 jours
-   90 jours
-   seniors
-   anti-stress
-   mobilité
-   motards
-   Qi Gong
-   respiration
-   méditation

------------------------------------------------------------------------

# Interface

Accueil :

-   séance du jour
-   reprendre la progression
-   historique
-   respiration
-   objectifs
-   statistiques

------------------------------------------------------------------------

# Assistant IA

Répond aux questions :

-   pourquoi ce mouvement ?
-   pourquoi cette respiration ?
-   pourquoi cette douleur ?
-   comment améliorer ma posture ?

Le coach adapte ensuite les exercices.

------------------------------------------------------------------------

# Vision à long terme

Créer un moteur générique de coaching IA pouvant être décliné pour :

-   Tai Chi AI
-   Qi Gong AI
-   Yoga AI
-   Stretching AI
-   Équilibre Seniors AI

Le cœur logiciel reste identique, seuls les contenus et les modèles
changent.

# Pourquoi ce projet ?

Ce projet complète parfaitement l'écosystème existant :

-   mutualisation de la stack technique
-   intégration avec Virtual Humans Studio
-   possibilité d'utiliser des avatars comme enseignants
-   fort potentiel pour les seniors, le bien-être et la prévention

Il s'agit d'une idée à conserver dans le backlog stratégique pour un
développement après les projets prioritaires.
